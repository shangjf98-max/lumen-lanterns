Lumen Lanterns is an original mirror-beam puzzle game: rotate mirrors to steer beams of light into lanterns across 6 handcrafted levels, with prisms that split beams, color filters, star ratings, undo, and synthesized sound. No build step — static files under game/ play offline in desktop Chrome.

## Run it

```sh
python3 -m http.server 8080 --directory game
# Open http://localhost:8080 in desktop Chrome
```
